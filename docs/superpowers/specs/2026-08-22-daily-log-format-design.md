# FormPilot AI 每日记录精简格式设计

## 目标

将 `docs/DAILY_LOG.md` 统一为便于每天维护的简洁记录，同时保留项目验证证据和真实学习状态。

## 记录结构

每个学习日固定包含五部分：

1. **今日目标**：最多三条，描述当天预期结果。
2. **完成情况**：只记录实际完成的代码、文档或配置。
3. **验证结果**：记录实际执行的测试、构建结果和提交；未运行时明确写未运行。
4. **学习与问题**：区分已经通过复述确认的理解、仍需巩固的内容和关键排错结论，不代替学习者编造反馈。
5. **明日第一步**：只写下一次开始时最先执行的一项任务。

## 历史记录迁移

- Day 1、Day 2 全部改用五段式格式。
- 合并重复的计划、完成项和验证描述。
- 删除评分表、重复检查清单和冗长的 Codex 使用记录。
- 保留构建或测试失败、Git 提交、重要技术断点以及尚未确认的理解情况。

## 每日更新规则

每天学习结束后，Codex 检查实际改动，运行与当日范围相符的测试和生产构建，再更新当天总结。所有结论必须有代码、命令结果或学习者复述作为依据。

若当天没有开发，只记录实际发生的计划或文档调整，不虚构测试、完成情况或理解程度。
