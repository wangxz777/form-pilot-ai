# FormPilot AI 前端薄骨架设计

## 目标

参考 `docs/ui` 中的编辑器界面，搭建可运行、可导航的前端薄骨架。当前阶段只确定应用入口、页面边界和整体布局，不实现 Schema、表单渲染、编辑状态、弹窗、AI 或 CloudBase。

## 应用结构

- `src/main.ts` 注册 Vue Router、Pinia、Element Plus 和全局样式。
- `src/App.vue` 只承担应用壳职责，渲染 `RouterView`。
- `/` 对应首页，展示项目名称、简短定位和进入编辑器的入口。
- `/editor` 对应编辑器页，展示顶部工具栏与三栏静态骨架。

不提前创建 Store、Schema、字段组件、弹窗、服务端接口或未来业务空文件。

## 编辑器布局

顶部工具栏约 72px 高：

- 左侧显示 FormPilot AI、当前表单名称和保存状态占位。
- 右侧显示预览、导入、导出、AI 生成按钮。
- 按钮用于建立视觉结构，当前不绑定业务行为。

主体占据剩余视口高度：

- 左栏约 320px，包含“字段”标题、数量占位、添加字段按钮和空状态。
- 中栏自适应，包含“实时预览”标题和居中的白色表单画布卡片。
- 右栏约 330px，包含“字段属性”标题和未选择字段的空状态。

桌面端用浅灰边框分隔三栏；中间区域采用浅灰背景。窄于 960px 时改为纵向排列，确保内容不横向溢出。

## 视觉约束

- 使用 Element Plus 的基础控件和默认交互状态。
- 颜色以白色、浅灰和 Element Plus 主蓝色为主。
- 面板使用轻边框，预览画布使用轻阴影。
- 只做接近参考图的结构和层级，不做像素级还原或视觉精修。
