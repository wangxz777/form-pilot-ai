# FormPilot AI 前端薄骨架实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 参考 `docs/ui` 搭建具有首页、编辑器路由、顶部工具栏和响应式三栏布局的可运行前端骨架。

**架构：** `main.ts` 负责注册 Router、Pinia、Element Plus 与全局样式；`App.vue` 只渲染当前路由页面。首页提供编辑器入口，编辑器页只表达视觉结构，不承载 Schema、表单状态或弹窗行为。

**技术栈：** Vue 3、TypeScript、Vue Router、Pinia、Element Plus、CSS、Vite。

---

### 任务 1：搭建可导航的前端薄骨架

**文件：**

- 修改：`src/main.ts`
- 修改：`src/App.vue`
- 创建：`src/router/index.ts`
- 创建：`src/views/HomeView.vue`
- 创建：`src/views/EditorView/EditorView.vue`
- 创建：`src/styles/main.scss`
- 修改：`package.json`
- 修改：`pnpm-lock.yaml`

- [x] **步骤 1：核对依赖与当前工作区**

  确认 `vue-router`、`pinia`、`element-plus` 已在 `package.json` 中，且 lockfile 与清单同步。保留用户主动删除的旧 Schema、数据、工具和测试文件，不恢复、不暂存它们。

  运行：

  ```bash
  pnpm list vue-router pinia element-plus --depth 0
  git status --short
  ```

- [x] **步骤 2：配置 Router 和应用入口**

  在 `src/router/index.ts` 创建 `createWebHistory(import.meta.env.BASE_URL)` 路由实例，静态导入 `HomeView` 和 `EditorView`，分别注册 `/` 与 `/editor`。

  在 `src/main.ts` 创建应用后，依次注册 Pinia、Router、Element Plus，再挂载到 `#app`。导入 Element Plus 样式和 `src/styles/main.scss`。

- [x] **步骤 3：建立纯路由应用壳**

  `src/App.vue` 只包含 `RouterView`，不保留旧表单、页面容器或业务状态。

- [x] **步骤 4：实现首页**

  `HomeView.vue` 展示 FormPilot AI 名称、“自然语言动态表单生成器”定位和一个进入 `/editor` 的主按钮。使用 `RouterLink` 完成导航，不编写命令式跳转逻辑。

- [x] **步骤 5：实现编辑器静态结构**

  `EditorView.vue` 使用语义化的 `header`、`aside`、`main` 组织：
  - 工具栏左侧：品牌名、当前表单名、绿色保存状态文本。
  - 工具栏右侧：预览、导入、导出、AI 生成四个 Element Plus 按钮，不绑定点击行为。
  - 左栏：字段标题、数量 0、添加字段按钮和空状态。
  - 中栏：实时预览标题、白色画布、表单标题及无字段提示。
  - 右栏：字段属性标题和未选择字段提示。

  不创建 Store、Schema、字段渲染器、弹窗或服务端文件。

- [x] **步骤 6：实现全局与响应式样式**

  `src/styles/main.scss` 完成基础重置、首页居中布局、72px 工具栏、`320px minmax(0, 1fr) 330px` 三栏网格、浅灰背景、边框和预览画布阴影。

  在 `max-width: 960px` 媒体查询中将工具栏内容和编辑器主体改为纵向排列，将三栏宽度改为 `1fr`，并确保 `body` 与页面容器不产生横向滚动。

- [x] **步骤 7：验证**

  运行：

  ```bash
  pnpm build
  pnpm dev
  ```

  使用浏览器分别打开 `/` 与 `/editor`，检查导航、顶部工具栏、三栏层级和 960px 以下单列布局。确认控制台无错误，页面无横向溢出。

- [x] **步骤 8：提交范围内文件**

  只暂存本任务文件和计划，不暂存用户删除的旧业务文件：

  ```bash
  git add package.json pnpm-lock.yaml src/main.ts src/App.vue src/router/index.ts src/views/HomeView.vue src/views/EditorView/EditorView.vue src/styles/main.scss
  git add -f docs/superpowers/plans/2026-08-23-app-shell.md
  ```
